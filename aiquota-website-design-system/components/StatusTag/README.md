# StatusTag

A small capsule with a status dot and a word, for quota states where a full dial is too much.

**States** follow the dial: default, `aq-tag--warning` (85%+), `aq-tag--critical` (95%+ or at the limit), `aq-tag--off` (not reported).

**Rules**: always a word, never a dot alone. Use the app's words: *Nearing limit*, *Limit reached*, *Not reported*.
