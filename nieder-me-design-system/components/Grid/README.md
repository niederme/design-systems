# Grid

The grid keeps the left rail, reading column and wider editorial blocks in deliberate relation to each other.

- 12 columns (`--grid-cols`) of 69px, 40px gutters (`--grid-gutter`), 1268px max (`--grid-width`).
- **3 / 6 / 3 split**: resume-style or content plus sidebar compositions.
- **4 / 8 editorial split**: section headers with narrative content, or media-led story blocks. `work-article-grid` is this split.
- **Wide specimen row**: hero treatments, scale samples, strong visual punctuation.
- On desktop the page sits to the right of the 90px icon rail (`SiteNav`).
