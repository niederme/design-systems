# Spacing

Spacing is generous by default. Sections should feel intentionally paced, with strong vertical breaks and clean internal grouping.

- **8px**: micro offsets, icon nudges, tight text pairings.
- **16px**: compact groups, small insets, tight control spacing.
- **24px**: default rhythm between a heading and its copy.
- **40px**: the grid gutter (`--grid-gutter`) and the major composition interval.
- **72px and up**: section transitions and large editorial pauses.

Other steps in use: 5, 10, 12, 15, 20 and 28px. Radii: 0 for rules and square edges; 5, 10, 14 or 16px for subtle frames; 999px for pills.
