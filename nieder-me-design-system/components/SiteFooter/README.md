# SiteFooter

The footer on every page: `footer.site-footer` with a `rule`, then `site-footer-grid`.

- `site-footer-brand`: `site-footer-name` (*John Niedermeyer*), `site-footer-role` in `--accent` (*Product Design & Direction*), then `site-footer-social`, a list of `social-icon` links (`social-icon-github`, `-linkedin`, `-x`, `-instagram`, `-email`) drawn from `assets/icons/social/`.
- `site-footer-meta` and `site-footer-utility-links`: copyright and small links in `--footer-meta`.
- `site-footer-column` blocks (`site-footer-column-site`, `site-footer-column-work`) each hold a heading and `site-footer-links`.
