# Principles

The four rules every page follows. These are guidance, not a component to reuse.

- **Editorial first.** Pages read with the confidence of a magazine layout, not a generic template library.
- **Structure stays visible.** Grid, rules, alignment and spacing do real compositional work. They aren't decoration.
- **Accent with restraint.** Red (`--accent`) directs attention, separates hierarchy and signals interaction. Keep it rare.
- **Warm precision.** Exacting without feeling cold. Human phrasing and tactile surfaces matter.

The card uses the style-guide layout (`styleguide-section`, `styleguide-principles`). Those classes are for documenting the system, not for site pages.
