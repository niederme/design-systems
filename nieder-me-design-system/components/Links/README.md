# Links

Links do most of the work. Buttons are used sparingly, when an action deserves emphasis.

- Use a link when the destination changes. Use a real `<button>` only for in-place controls, like the theme and column toggles in `SiteNav`.
- Prominent link: `<a class="styleguide-button-lg">View Case Study</a>` (18px) or `<a class="styleguide-button-md">View Work</a>` (16px). A white block with black Söhne halbfett and a 5px radius.
- Inline links: plain `<a>` in running text. They take `--accent` on hover, with a visible `--focus-ring` on focus.
