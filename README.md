# Design systems

John Niedermeyer's design systems, kept as the copies used for Claude Design.

- `aiquota-app-design-system/`: AIQuota on iPhone, iPad and Mac, taken from the SwiftUI code. Source: [niederme/ai-quota](https://github.com/niederme/ai-quota).
- `aiquota-website-design-system/`: the AIQuota 2.0 website, matched to the shipping apps. Source: [niederme/ai-quota](https://github.com/niederme/ai-quota).
- `nieder-me-design-system/`: nieder.me, copied from `design-system/` in the nieder.me repo. Source: [niederme/nieder.me](https://github.com/niederme/nieder.me/tree/main/design-system).
