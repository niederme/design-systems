# Color

White paper, one house green, and one colour per child. Colour carries hierarchy, so it stays scarce.

**Use**
- `green`: the brand, school and home headings, their rule, links, the primary button.
- `child-1` to `child-3`: everything that belongs to that child (heading, rule, tab, score line), in name order.
- `ink` for titles, `text` for notes, `muted` for dates and sources.
- `warn` on `warn-bg` for something not checked yet; `red` only for a source that failed.

**Rules**
- Never use a child colour for anything that isn't theirs.
- Red is never decoration or emphasis.
