# Typography

One rounded system font (`ui-rounded`, then the system sans). Eight roles; each sets size, leading, weight and tracking.

**Rules**
- 15px is the floor. Nothing smaller anywhere, including captions and source lines.
- Hierarchy is colour and weight. Don't shrink type to make something secondary.
- One size per row: a date beside a title is the same size as the title.
- Headings use & instead of "and".
- `heading` is the only role with tight leading (1.1), because it's the only one that wraps as a name.
