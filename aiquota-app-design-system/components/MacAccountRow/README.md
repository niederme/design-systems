# MacAccountRow

One account in the Mac sheet (`MacAccountOverviewItem`).

- `radius-mac-card`, `space-16` padding, regular material, 1px `card-edge-mac` border; hover or focus adds `hover-mac` over 0.12s.
- `aq-dial--mac`, then details `space-20` away: name in `mac-service`, plan in `mac-detail`, reset captions in `mac-caption`, `reset-accent` (*Resets Fri at 3:40 PM*, *7d Resets Tue at 10:07 PM*). Problems in `warning`; other status in `secondary`.
- Codex adds *Token activity* and a `TokenHeatmap`.
- Rows stack `space-16` apart.
