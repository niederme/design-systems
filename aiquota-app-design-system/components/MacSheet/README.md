# MacSheet

The Mac menu-bar window (`PopoverView`).

- 420pt wide for one account, 480pt for more; height fits content up to 88% of the screen.
- Header: *AIQuota* in `mac-wordmark`, refresh on the right; 16pt sides and top, 12pt bottom.
- Body: the Mac `NoticeBanner` when present, then `MacAccountRow`s, 16pt side padding.
- Footer: *Settings* left, *Quit* right, last refresh time centred in `tertiary`; `mac-footer`, 14pt sides, 8pt vertical.
- Surface: the Mac sheet in `Grounds`.
